# 智小匠前端视觉复原

当前为班主任端 MVP：保留参考控制台视觉复原，同时提供智小匠登录、班级概览、学生档案、成长画像、机智币、预警、帮扶、六机任务和班级诊改页面。后端在线时页面读取真实 API，离线时明确显示演示数据。

## 启动

```sh
npm install
npm run dev
```

打开终端输出的本地地址。默认展示参考控制台，使用侧栏底部或顶部调色板切换“智小匠”视图；直接访问 `/?view=school` 也可打开智小匠视图。

```sh
npm run build
```

## 可操作范围

- 展开或折叠侧栏；移动端打开导航抽屉。
- 展开或收起设置引导。
- 搜索菜单（支持 Command/Ctrl + K）。
- 打开通知、版本选择、录入积分/成长记录、发布任务、创建帮扶和新增诊改目标弹窗。
- 切换参考版和智小匠业务适配版。

表单保存通过 `/api/v1` 写入后端；端到端链路由后端的 H2 隔离测试覆盖（在仓库根目录执行 `mvn test`）。

## 复原依据与边界

以用户提供的 bytecat 控制台截图为主要依据，保留暖白底、衬线中文、珊瑚橙、细灰边框、轻阴影和紧凑布局。布局按 CSS 像素响应，截图外围黑框不属于页面。

使用 Vue 3、TypeScript 和 Lucide 图标；字体作为依赖打包，不依赖在线字体 CDN。Logo 使用本项目的机器人符号，不复制原站商标。像素角色为自行绘制的近似图形。当前是单页视觉复原，不是原站全站镜像；字体、标志和数据内容存在明确差异。

# 学生端实施与验收记录

## 完整目标

1. 登录与首页：学生身份、本人权限、真实待办。
2. 任务闭环：查看、提交、教师退回、补充提交、评价、结果与积分反馈。
3. 成长与机智币：本人画像、学生记录审核、可追踪流水。
4. 成长计划与消息：教师显式发布可见内容、学生执行、阶段反馈和已读状态。
5. 手机端验收：键盘、附件上传、重复提交、空状态和越权测试。

最终验收必须完成学生登录至教师确认后看到成长记录与积分变化的完整案例；单独构建或权限测试通过不代表目标完成。

## 2026-09-17：身份边界基础

已实现（源码与隔离 H2 测试，尚未部署）：

- `/api/v1/student-portal/**` 仅 STUDENT 角色；其他业务接口仅 TEACHER 角色；登录、CSRF 公共入口不变。
- 独立 `student_account` 表绑定用户与学生，一对一，外键约束；包含后续首次改密使用的标志，但首次改密流程尚未实现。
- `StudentScope` 从认证身份解析学生，检查绑定、数据库角色及学生在籍状态，不采信客户端 studentId。
- `/student-portal/home` 返回本人资料、数据库任务待办与积分余额，不含预警或内部帮扶备注。
- `/student-portal/points` 返回本人分页积分流水，复用反向流水追踪能力。
- `StudentPortalSecurityTest` 通过：匿名拒绝、学生访问教师接口拒绝、教师访问学生接口拒绝、伪造 studentId 不泄露他人资料/积分、归档拒绝、教师列表仍可用。

测试显式使用独立内存库与禁用 Redis；未操作共享 MySQL/Redis。执行方式：`mvn -pl zhixiaojiang-server -Dtest=StudentPortalSecurityTest test`。

部署注意：新增 `src/main/resources/student-portal-schema.sql` 是增量建表文件，不能用演示 schema 初始化现有数据库。当前未执行远端建表，未创建真实学生账号，也未发布学生页面。

## 2026-09-17：账号与成长审核

已实现，尚未部署：

- 教师在学生档案详情开通绑定账号，只允许本班在籍学生，重复绑定或用户名冲突拒绝。口令 BCrypt 存储，响应与审计不返回明文。
- 首次登录进入改密表单；后端在改密前拒绝所有学生业务读取/写入。新密码 12–64 字符且 UTF-8 不超过 BCrypt 的 72 字节范围。
- 改密后数据库会话版本递增，所有旧学生会话在后续请求失效；新密码重新登录后进入学生首页。归档也会使学生身份校验失败。会话 Cookie 增加 SameSite=Lax，并使用无状态安全上下文。
- 学生导航补齐首页、任务、成长、机智币、我的；我的提供改密，成长页读取本人四维评价、评价依据、成绩趋势、技能评分、任务活动与自报记录。
- 学生可以提交活动、技能作品、个人反思。待审核记录不进入正式活动统计；教师在档案详情审核，只有通过的活动才新增活动记录，且重复审核不重复新增。技能/反思通过后保留成果，不自动生成技能或四维评分。
- 教师反馈与自报记录状态可在学生成长页读取。退回记录保留原文；当前尚无关联旧记录的补充重提入口（需补齐）。

验证：全部 14 项后端测试通过，前端构建通过。新增覆盖教师开通、重复开通、首次改密强制、旧密码拒绝、两个旧会话全部失效、学生不能开通账号、待审核不计活动、重复审核只计一次、审核不改四维评价、本人数据及非法日期范围。修正 H2 演示用户表自增主键，与正式 schema 保持一致。

待完成的完整目标仍包括：成长记录关联重提、附件上传与鉴权、成长计划发布/执行/反馈、消息与已读、MySQL 集成、完整浏览器案例、手机与键盘验收。未因本轮测试通过而标记整个目标完成。

- 学生菜单按用户要求改为教师端同款顶栏与左侧分组侧栏，桌面可折叠、手机可展开；仅显示学生功能。

## 2026-09-17：任务附件与成长记录关联重提

- 任务附件接入学生提交和教师审核页面，支持 PNG/JPEG/PDF，每个不超过 2 MiB、每次最多 3 个，学生累计 50 MiB；文件头和扩展名校验不等同于病毒扫描。附件保存在数据库中，下载强制附件响应，不以内联页面展示。
- 上传请求键防重，学生只能上传和读取本人任务附件。教师只能读取本班已经提交的附件；暂存附件不对教师开放。已提交附件不能移除。绑定附件、任务提交和状态变化在同一事务内，绑定其他任务附件时回滚。
- 学生成长记录支持从退回记录发起补充，新旧记录通过独立关联表保存，旧内容及教师反馈不覆盖。每条退回记录只能产生一个直接后继；重复请求返回已有结果，已通过记录拒绝重提。学生端和教师端显示关联编号。
- 隔离 H2 全套 16 项测试通过，涵盖完整任务退回/补充/确认流程，以及附件越权、提交前教师不可读、重复上传、非法文件、大小限制、非法绑定回滚、已提交附件不可删除；成长测试扩展了重提幂等、原文保留、禁止已通过记录重提。前端构建通过。
- 本轮未修改京东白名单、未更新远端数据库结构、未重启现有应用。新增表 `task_attachment`、`student_growth_revision` 仍需在部署时核对并执行增量初始化。

尚未证明完成：真实 MySQL 完整案例、浏览器与手机/键盘/文件选择交互、跨版本计划历史展示及远端当前版本验收。隔离测试通过不能替代这些验收，目标保持进行中。
